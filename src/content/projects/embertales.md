EmberTales is a production voice-AI product built end to end: a React/Vite front end, a Python + Pipecat voice pipeline, and Supabase for data — deployed with full CI/CD across Vercel and Modal. The hard part is conversational: the agent reads aloud, handles barge-in interruptions naturally, and keeps the discussion anchored to the book the child is reading.
